# Trekka API Contribution Guide

The backend lives inside the Trekka monorepo, and all shared processes are documented centrally.

- Main contribution guide: `../../CONTRIBUTING.md`
- Repository overview & environment setup: `../../README.md`

API quick reference:

```bash
npm install
npm run start:dev
npm run test
npm run lint
```

Use the root scripts (for example, `../../scripts/dev.sh` and `../../scripts/generate-encryption-key.js`) and keep changes aligned with the standards defined in the root documentation.
