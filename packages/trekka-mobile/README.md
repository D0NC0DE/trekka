# Trekka Mobile (Flutter)

This package is part of the Trekka monorepo. All onboarding, architecture, and workflow guidance now lives in the root documentation.

- Repository overview & installation: `../../README.md`
- Contribution workflow & coding standards: `../../CONTRIBUTING.md`

Quick references:

```bash
# Install dependencies from this directory
flutter pub get

# Run the app (pass USE_MOCKS/API_BASE_URL as needed)
flutter run --dart-define=USE_MOCKS=true
```

For scripts that start both the API and mobile client together, use the root `scripts/dev.sh`.
